# 03_demo — Frontend

React + TypeScript frontend for the drowsiness detection demo application.

## Setup

### 1. Install dependencies

```bash
npm install
```

### 2. Start the development server

```bash
npm run dev
```

### 3. Open in browser

Navigate to: http://localhost:5173

Make sure the backend is running at `http://localhost:8000` before starting a stream session.

## Build for production

```bash
npm run build
```
